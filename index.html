Machine Learning Projects in Biomedical Computing

I'm Arel, a high-school student learning machine learning through projects in medicine, biology, and a few other fields. Each project has a write-up, code, and a browser demo. The write-ups include the data splits, test results, and mistakes I found along the way. These are educational projects, not medical devices.

Educational content only. Nothing on this site constitutes medical, financial, or professional advice, and none of these projects are certified products or devices. See the full disclaimer.

Biomedical projects

MoleCheck

Privacy-preserving skin-lesion analysis: a YOLO11 computer-vision classifier trained on 11,720 dermatology images, running fully on-device via Flutter and TensorFlow Lite so no user data leaves the phone.

Computer vision TFLite Flutter Live demo

ECG Arrhythmia Classification

A 1D convolutional neural network for heartbeat classification on the MIT-BIH database, with an inter-patient evaluation documenting the drop from 96% in controlled settings to 44% on unseen patients.

Signal processing 1D CNN ONNX Live demo

ADHD Classification from EEG

A multi-channel 1D CNN classifying pediatric EEG by study group, evaluated with a strict subject-level split to measure genuine generalization — 92% accuracy on unseen subjects.

EEG 1D CNN ONNX Live demo

Leukemia Cell Subtyping

A computer-vision classifier subtyping leukemic blood cells across four classes at 99.8%, with a critical analysis of why that figure reflects a dataset limitation rather than true clinical performance.

Computer vision YOLO ONNX Live demo

A bilingual cognitive-load experiment: does a clue in your weaker language slow visual search, make you miss a hidden gorilla, or tire you faster? Built and tested; awaiting mentor review and ethics approval — no data collected yet.

Additional projects

Two projects outside the biomedical focus, included to show broader range in computer science — reinforcement learning and applied machine learning on financial time series.

Stock Volatility & Sentiment

A neural network predicting next-week volatility risk from price and news-sentiment features, including a controlled ablation demonstrating that the sentiment signal did not improve performance.
